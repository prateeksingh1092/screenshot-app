# SEC: round 1

Threat model: Prateek's FileVault-capable Intel Mac (T2). Adversaries: later viewer or borrower of the unlocked Mac, image recipients, same-user processes (clipboard managers), Time Machine and APFS snapshots, same-Apple-ID devices (Universal Clipboard, iCloud Drive). Out of scope: root, kernel, forensic attacks on a locked FileVault disk.

- **SEC-1 (blocker; decisions 17, 23): solid redaction can still show the original.** Snapzy's filled rectangle allows any alpha, corner radius, stroke, antialiasing; its blur and magnifier sample `sourceImage` (`AnnotateAnnotationRenderer.swift:61-76, 277-278, 641-660`); fractional pixels after crop, rotate, scale. Amendment: a dedicated redaction tool: fixed colour at alpha 1, no radius or stroke, `.copy` blend, antialiasing off, rect snapped outward to whole output pixels after transforms, applied to the base layer before any sampling effect, which reads the redacted composite. Test at 1x and 2x with fractional coordinates and an overlapping blur or magnifier: every pixel inside equals the fill, alpha 255.
- **SEC-2 (blocker; decision 13): own windows and "protected" windows get captured.** `sharingType = .none` is ignored by ScreenCaptureKit (Apple forums 792152); a stale unredacted thumbnail can be baked into the next full-screen capture; Snapzy's self-exclusion is optional (`ScreenCaptureManager.swift:2691-2718`; `CaptureViewModel.swift:1384-1389`). Amendment: every capture uses an `SCContentFilter` excluding this app's bundle, with no `sharingType` fallback; manual check that thumbnail, editor and history never appear in a new capture.
- **SEC-3 (major; decisions 4, 17): clipboard outlives redaction and history.** Snapzy writes a history file URL plus image (`ClipboardHelper.swift:108-133`); Universal Clipboard syncs; copy-then-redact leaves the unredacted image; clipboard managers keep copies forever. Amendment: image data only; record change count at copy and replace with the rendered result on finalize if unchanged; never read the general clipboard; settings text says delivered copies can't be recalled. `.currentHostOnly` and the concealed-type marker are Prateek's call.
- **SEC-4 (major; decision 17): drag exposes history files** (`QuickAccessDraggableView.swift:522-546`). Amendment: `NSFilePromiseProvider` writing the rendered revision, copy-only operation mask, staging file per revision deleted at session end and swept at launch; test that a Trash drop is refused and the history file keeps its path.
- **SEC-5 (major; decision 16): "memory only" needs a testable definition.** Risks: `NSDocument` autosave, window restoration, Live Text on the original canvas, thumbnail still showing the original, undo after Copy, whole-display frames before crop, swap and sleep image. Amendment: reword as "the app never writes the original to storage"; forbid `NSDocument`/autosave, window restoration for editor and thumbnail, disk image caches, Quick Look generation for pending captures; drop pre-crop frames after cropping; refresh the thumbnail from the rendered revision; specify whether Copy closes the editor; never promise zeroed memory.
- **SEC-6 (major; decisions 5, 18, 20): deletion can't be promised as written.** Snapzy trashes deleted history (`HistoryWindowController.swift:205-227`); Time Machine, snapshots, Spotlight, iCloud-synced export folders, SSD wear levelling, unsandboxed Application Support readable by same-user processes. Amendment: delete directly, not to Trash; history dir excluded from backup with a `.noindex` name; flag iCloud-synced export folders; promise only "removed from the app" and recommend FileVault; decide sandboxing with entitlements (decision 21).
- **SEC-7 (major; decision 25): logs still leak names** (`DiagnosticLogger.swift:81-93`; error descriptions embed paths). Amendment: logging API takes only an event enum, error domain and code, and allow-listed fields, no free-text strings; forbid window titles, app names, paths; unified-log and assertion messages static only; test fails on a planted secret name.
- **SEC-8 (minor; gap): OCR text in notifications** (`OCRNotificationContent.swift:28, 43-44`). Amendment: "Copied N characters" only, with a unit test.

Keep: decision 16 trade-off, decision 23 invariants (OCR on rendered result, opacity checks), decision 19 no URL scheme.

Questions for Prateek: (1) copies local-only (no Universal Clipboard) and hidden from clipboard managers? (2) a per-app capture exclusion list, for example password managers? (3) default export location: non-synced folder or Desktop?
