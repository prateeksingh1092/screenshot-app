# PLAT: round 1

- **PLAT-1 (blocker; decisions 21, 14): "locally signed" is undefined, so Screen Recording is re-granted on every rebuild.** TCC keys grants to the code-signing requirement; ad-hoc signatures pin one build (TN3127; Snapzy `docs/SELF_SIGNED_CERT.md:7`; relaunch after grant `ScreenCaptureManager.swift:192-199`). Amendment: one stable identity (Personal Team Apple Development or a self-signed cert, needs Prateek's approval), a separate development bundle id, one fixed install path, one signing path (Xcode or script, never both). Test: two rebuilds, `codesign -d -r-` shows the same requirement, no re-prompt.
- **PLAT-2 (blocker; decisions 13, 15, 22): Snapzy's capture fast path and overlay hiding break at macOS 26.** `CGDisplayCreateImage`/`CGWindowListCreateImage` (`ScreenCaptureManager.swift:355,382`; `AreaSelectionWindow.swift:702`) are marked obsoleted in macOS 15 in the SDK headers (`CGDirectDisplay.h:384`, `CGWindow.h:274`); compile failure is inference. `sharingType = .none` (`AreaSelectionWindow.swift:2396`) is ignored by ScreenCaptureKit (Apple forums 792152). Amendment: ScreenCaptureKit only; exclude own app via `SCContentFilter(excludingApplications:)`; hide overlays before capture; prefetch shareable content on hotkey; pixel tests that no overlay or thumbnail appears; measure latency on ScreenCaptureKit alone.
- **PLAT-3 (major; gap): recurring "bypassing the private window picker" alert** (macOS 15+, reported monthly; persistent-content-capture entitlement is VNC-only). Amendment: check permission before any overlay, never draw over a pending system alert; define denied, revoked and needs-relaunch states; add them to the manual checklist.
- **PLAT-4 (major; decisions 4, 19): shortcut mechanism and collisions.** Carbon `RegisterEventHotKey` needs no permission; event taps need Accessibility or Input Monitoring. ⇧⌘3/4/5 and ⌃ variants belong to the system; Snapzy's scrolling default ⇧⌘6 is the Touch Bar screenshot shortcut, which this Mac has. Amendment: Carbon only; defaults avoid enabled system shortcuts, or an explicit "replace system shortcuts" flow; validation rejects collisions.
- **PLAT-5 (major; decision 2): Accessibility scope.** Auto-scroll posts synthetic events (`ScrollingCaptureCoordinator.swift:548-555`), active-window lookup and pass-through overlay also need it. Amendment: v1 works with Screen Recording only; manual scrolling and window picking need no Accessibility; auto-scroll optional behind Accessibility with a manual fallback.
- **PLAT-6 (major; decision 15): arm64 is never executed here and Tahoe is the last Intel release** (WWDC25). Amendment: development builds native-arch only; universal only for release; arm64 labelled unverified; any distribution needs an Apple-silicon test run.
- **PLAT-7 (minor; decision 14): Xcode 26.6 is the last Xcode for this Mac** (macOS 26.5 SDK). Amendment: download from developer.apple.com (free Apple ID), `pkgutil --check-signature`, pin the SDK.
- **PLAT-8 (minor; decision 2): Spaces and full-screen apps.** Amendment: v1 window capture covers windows visible on the current Space; overlay-over-full-screen and Space switching go on the manual checklist.

Keep: decision 14 package core, decision 23 manual checklist, decision 19 single command layer.

Questions for Prateek: (1) approve Personal Team sign-in or a self-signed certificate; (2) take over ⇧⌘3/4/5 or use non-conflicting defaults; (3) auto-scroll (needs Accessibility) in v1, or manual only.
