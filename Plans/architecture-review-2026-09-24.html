Problem: the History window reload makes n+1 full reads through three actor hops, and it queues behind Done encodes and stitching. The live loop also found D19: row actions fail after "Try Again".

  • No file paths leak across the seam
  • Smaller lifecycle interface
The plan is right not to split HistoryStore into five modules; that would create shallow modules. Gate it on DA-4/DA-11.

Top recommendation

One Capture renderer for preview and Finalized capture

It removes the Critical D1 class (saved ≠ seen) and puts "preview at scale s equals the downsampled output" behind a single interface. The pending capture record (#2) comes next, and makes both planned presenters unnecessary.
